Spring permet de valider les données d’un formulaire grâce à des annotations de validation placées directement dans la classe modèle.

Voici le fonctionnement :
- Définition les règles de validation dans le modèle (utilisation des annotations comme @NotBlank, @NotNull, @Min, @Max, @Size pour définir les conditions que les données doivent respecter)
- Déclenchement de la validation dans le contrôleur avec @Valid
- Récupération des erreurs avec BindingResult pour enregistrer les erreurs détectées et hasErrors() permet de vérifier si des erreurs sont présentes
- Affichage des erreurs dans la vue avec th:errors

Le message d'erreur affiché provient de l’attribut message de l’annotation, sinon de messages.properties, sinon du message par défaut.
